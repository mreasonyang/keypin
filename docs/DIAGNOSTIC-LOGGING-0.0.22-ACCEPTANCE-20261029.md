## 实际安装与日志检查

1. 在 Finder 挂载已验证 DMG，通过 Finder 复制替换安装最终应用。对应用附加隔离属性后首次启动，Gatekeeper 放行并由 App Translocation 运行；该受控隔离测试观察到独立可见窗口数为 0。显式重新打开后，主面板、设置和关于页正常，显示 0.0.22（23）。
2. 设置页实际确认应用标识开关为 off，登录启动开启，自动检查和自动下载安装仍关闭；未在用户实机开启应用标识采集。
3. 仅开启测试进程自己的 Carbon 安全输入约 10 秒：实际应用出现安全输入等待提示，释放后提示自动消失。日志记录同一安全输入片段的开始、结束、已观察时长 9.672 秒及自动切换恢复。
4. 实际日志文件夹为 0700，文件为 0600；检查记录中没有其他应用的上下文、占用者信息和测试文档输入文本。独立 TextEdit 文档的基本文字输入及焦点切换可用，输入源保持为所选来源。本轮没有据此声称完成真实中文候选或组合输入验收。
5. 7 天逐条过期、混合文件清理、每分钟限频、关键事件额度、超额汇总、64 条待写队列、关闭后旧标识清理和失败回报由受控时钟/临时文件系统测试覆盖，不是实际等待 7 天或制造真实磁盘满。

1. 恢复完整、未改版本元数据的公开 0.0.21（22）基线，核对全部应用文件与公开 ZIP 相同。恢复草稿测试前的单个 GUI 构建记录；没有修改输入法配置、更新源、公钥或签名要求。

5. `/Applications/KeyPin.app` 的文件、链接和可执行位与公开 ZIP 完全一致；签名、公证票据和 Gatekeeper 再验通过。当前为单个原生 arm64 进程，验证窗口关闭后继续在菜单栏运行。

## 证据边界

本机为 macOS 27.0.1、arm64，本轮没有在本机强制执行 Intel 进程。云端 Intel/macOS 15 结果不替代用户实体 Intel 设备或 macOS 13/14 验收。无人值守自动更新、新的真实中文候选/组合输入、长时间跨 App 输入及睡眠唤醒仍未新增验收。系统报告的安全输入占用 PID 没有稳定公开契约，可选采集开启后仍可能未知。

公开证据不包含原始诊断日志、第三方应用标识或签名凭据。机器回执：[DIAGNOSTIC-LOGGING-0.0.22-ACCEPTANCE-20261029.json](DIAGNOSTIC-LOGGING-0.0.22-ACCEPTANCE-20261029.json)。本机逐阶段产物保存在忽略目录 `dist/diagnostics-release-0.0.22/`。
