这里保留面板布局、配置引导、状态和更新检查的详细约定。日常上手见 README。

## 日常使用

主窗口和菜单栏弹出面板统一为 **320 pt 宽，高度随内容变化**。输入法数量、界面语言和错误提示会影响所需高度。通常高度上限为 **580 pt**，小屏幕采用更低上限；内容超出时可滚动，标题和导航固定在顶部，操作按钮仍可到达。页面或引导步骤切换后重置外层滚动位置。

主面板直接显示输入法列表，通过选中标记与“当前”区分保持目标和系统正在使用的输入法；切换、等待、安全输入及错误按需提示。列表固定首项为 **“跟随系统”**，副标题为 **“不保持输入法”**；其余项目为系统可用输入法。列表使用原生 Liquid Glass；菜单栏、列表和配置引导共享输入法自带图标，保留原始色彩和比例，单色图标随深浅模式变化；缺少图标时显示键盘图标。主面板无重复状态卡、列表标题与操作说明。设置页采用平整的紧凑行：左侧名称，右侧登录开关或当前语言；语言菜单收起时显示短名称，展开保留完整选项和选中标记。没有彩色图标与嵌套卡片，登录说明通过悬停和辅助功能提供；“保持如何工作”按需展开。关于信息位于独立页面。超过 6 个输入法时，列表保留约 **6.5 行**的滚动区域；搜索只剩一个结果或没有结果时也保持相同高度，避免面板随输入跳动。

首次打开显示两步配置引导：选择输入法，再确认是否立即开始保持、是否登录启动。完成前只保存草稿；关闭“立即开始保持”时只保存目标。“稍后设置”会记住跳过状态，设置页可以重新打开引导。保存失败会保留草稿，切换或登录启动失败会显示实际错误。重新打开引导会清空上次搜索；同一次引导中返回上一步会保留搜索。

搜索支持原生撤销、重做、剪切、复制、粘贴和全选快捷键。选择输入法或恢复保持前会重新校验系统目录，避免对刚移除的输入法保存新的保持请求。切换界面语言时，已有错误提示的应用文案一起更新，系统提供的原始错误详情保留原文。

在主面板选择真实输入法，会立即切换并启用保持；之后切换 App 或输入法时，应用会自动切回目标。选择“跟随系统”会停用保持，允许自由切换，且记住上次目标；这一操作不会切换当前输入法。关闭窗口后应用继续在菜单栏运行，退出按钮会停止应用。

菜单栏只显示**系统当前输入法自己的图标**，不再附带名称文字；正在切换或切换失败时也跟随实际输入源，不提前展示保持目标。输入法的单色透明图标随菜单栏明暗着色，彩色图或带黑白背景的图标保留原貌。没有可用图标时显示 App 的三键键盘标记。暂停时变淡；完整名称与运行状态放在悬停说明和辅助功能描述中。源切换、输入法目录变化或重新打开面板会刷新图标，日常状态轮询不重复读取图标文件。面板与 CLI 使用同一套状态：

| 状态值 | 含义 |
| --- | --- |
| `setup` | 尚未选择输入法 |
| `paused` | 已暂停自动保持 |
| `keeping` | 已开启保持，当前输入法与目标一致 |
| `switching` | 正在执行一次切换 |
| `waiting` | 当前输入法与目标不同，等待切回 |
| `secure_input` | 安全输入期间暂缓切换 |
| `conflict_paused` | 检测到反复切换，GUI 暂缓保持并等待重试 |
| `missing_source` | 目标输入法当前不可用 |
| `error` | 配置或切换发生错误 |
| `stopped` | 应用未运行，用于命令行状态 |

运行状态优先反映配置错误、目标缺失等需要处理的问题；暂停时不因安全输入而显示正在干预。切换恢复成功后清除过期切换错误，保存和登录启动错误仍单独保留。

GUI 默认在本机记录状态变化、安全输入的进入/持续/退出及切换失败与恢复；设置页可打开日志文件夹。日志有容量上限，不记录输入内容，前台应用与系统报告的占用者分开标注。字段、保留范围与诊断限制见[本地诊断日志](diagnostics.md)。

为避免与系统或其他应用反复争抢输入法，同一个前台 App、同一个保持目标在 15 秒内最多尝试 3 次自动切回；再次需要切回时，先暂停 15 秒。持续冲突时暂停依次延长到 30、60、120 秒，上限 120 秒。期间输入法通知和每 2 秒的检查都不会继续切换或启动焦点辅助进程。成功切回及其通知回声不会清空计数；目标持续稳定 30 秒后才重置退让。切换到其他 App、改变保持目标、暂停后恢复，或主动点击重试/选择输入法会重置退让；KeyPin 自身及焦点辅助进程的激活不算切换 App。安全输入、缺失目标以及焦点辅助进程冷却中的空检查不消耗次数。面板以“切换冲突，暂缓保持”及可重试提示说明原因。这是 GUI 进程内的临时状态 `conflict_paused`；独立 CLI 状态读取不获取此计时器，仍按保存的保持意图和实际输入源报告 `waiting` / `keeping`。

被系统标记为中文、日文、韩文或越南文的输入源会通过短命焦点辅助进程执行切换；系统输入源 ID 匹配只证明选中了输入源，具体 App 的候选词、组合输入和焦点行为仍需实际验证。

## 关于与更新

关于页显示产品版本、构建号、最低系统版本和当前架构，并提供手动检查更新、自动检查、自动下载安装设置。两个自动选项默认关闭，由用户决定是否启用。正式版从 GitHub Releases 获取 Sparkle appcast 与安装包；Sparkle 校验更新清单和下载包的 Ed25519 签名，再处理安装与重启。系统信息统计关闭。

更新服务由 GUI 进程持有；CLI、短命焦点辅助进程和隔离预览不启动更新服务。没有有效更新公钥的本地开发包显示更新不可用，不尝试连接更新源。应用更新不改变输入法配置或登录项；保持目标和实际输入是否恢复，仍需要用真实更新安装验收，不能由单元测试替代。

完成配置后，更新安装后的首次桌面启动只恢复菜单栏常驻，不自动打开独立窗口。GUI 在取得单实例锁后记录当前构建号；构建号变化或从旧版迁移而尚无记录时采用此行为。同一构建的后续主动桌面启动、运行中重新打开应用，以及 `keypin open` / `gui` 仍显示窗口。首次配置和配置读取错误继续显示需要处理的界面；登录启动保持静默。
